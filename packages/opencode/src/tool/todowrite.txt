Maintain the session's user-visible task list. Use for 3+ distinct steps (not merely tool calls), work benefiting from planning, multiple user tasks, or an explicit todo request. Skip trivial or purely informational requests.

- Submit the full updated list with specific, actionable items; capture new instructions and follow-ups. Preserve user commands verbatim.
- States: pending = not started; in_progress = active; completed = finished; cancelled = no longer needed.
- Update as work advances, not in a final batch. Mark the current task in_progress before starting; keep exactly one active while work remains.
- Mark completed only after the work and required verification actually finish. Keep blocked or partial work in_progress and add an item identifying the blocker.

When in doubt, use it.
