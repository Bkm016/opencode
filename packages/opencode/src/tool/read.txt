Read an absolute filePath; missing paths fail. Images and PDFs return attachments; directories list entries with trailing / for subdirectories.

- Text uses `<line>: <content>` prefixes. offset is 1-based; limit defaults to 2000 lines. Lines over 2000 characters are truncated.
- Page with offset/limit; prefer a useful context window over repeated tiny slices. Read independent files in parallel.
- Use glob to locate filenames and grep to locate content in large files.
