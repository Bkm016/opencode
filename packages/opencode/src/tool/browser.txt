Drive a real browser to view rendered web pages, including client-rendered (JS-heavy) pages that the fetch tool cannot see. Use this to visually inspect pages you built (e.g. open http://localhost:3000 and screenshot to check your work), read dynamic content, and perform basic interactions.

Actions:
- navigate: open a URL (always the first step)
- screenshot: capture the current page as an image attachment you can see. Use full_page for long pages.
- get_content: read the rendered page as markdown (default), text, or html; optionally restricted to a CSS selector
- click / type_text / press_key / scroll / back: interact with the page by CSS selector or keyboard
- evaluate: run a JavaScript expression in the page and get its JSON result (e.g. inspect DOM state, read console-friendly globals)
- close: close the browser tab (also closes automatically after 2 minutes idle)

Guidelines:
- One page at a time: state is a single tab shared across calls. You MUST call navigate with a valid http(s) URL before any other action — click, type_text, screenshot, get_content, evaluate, scroll, press_key, and back all fail if no page is open.
- The evaluate action requires a `script` argument containing the JavaScript to run; calls without `script` are rejected.
- Prefer screenshot to verify visual work; prefer get_content for reading text.
- After click, scroll, or navigation, the page may have changed — screenshot or get_content again before assuming state.
- Requires permission. The browser runs headless on the OpenCode server machine by default.
