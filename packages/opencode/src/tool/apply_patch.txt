Edit files with a patch wrapped in `*** Begin Patch` and `*** End Patch`. Each operation requires one header:
- `*** Add File: <path>`: create; prefix every content line with `+`.
- `*** Delete File: <path>`: delete; no content follows.
- `*** Update File: <path>`: modify; optional `*** Move to: <path>` renames. Use `@@` context anchors, space-prefixed unchanged lines, `-` removals, and `+` additions.

Example patch:

```
*** Begin Patch
*** Add File: hello.txt
+Hello world
*** Update File: src/app.py
*** Move to: src/main.py
@@ def greet():
-print("Hi")
+print("Hello, world!")
*** Delete File: obsolete.txt
*** End Patch
```
